# اختبار قابلية الاستخدام

> البند **رابعاً** في ملفّ المشروع. ومسؤوله: **أحمد ناصر**.

## ⭐ أهمّ شيء في هذا الملفّ: اقرأه قبل الاختبار لا بعده

السؤال الختامي **الإلزامي** في ملفّ المشروع هو:

> «ما أبرز مشكلة في قابلية الاستخدام كشفها الاختبار **ولم تتوقّعها
> المجموعة** أثناء التصميم؟»

**وهذا سؤالٌ لا يُجاب بعد الاختبار.** إن لم نكتب ما نتوقّعه **قبله**،
صارت الإجابة اختلاقاً بعدياً — وذلك ظاهرٌ للمصحّح، لأنّ كلّ مشكلةٍ تبدو
متوقَّعةً بعد وقوعها.

فالقسم التالي يُملأ **قبل أوّل جلسة اختبار**، ويُختم بتاريخه.

## سيناريوهات الاختبار

> مشتقّةٌ من **المهامّ الثلاث** في `PLAN.md` — لا مخترعةٌ هنا.

### السيناريو ١: التسجيل في ورشة

> «تخيّل أنّك سمعت عن مبادرة واحة وتريد حضور ورشةٍ للمبتدئين.
> **سجّل نفسك في الورشة القادمة.**»

| | |
|---|---|
| **المسار المتوقَّع** | الرئيسية ← الورش ← تواصل ← ملء النموذج |
| **النجاح** | أرسل النموذج بنجاح |
| **الزمن المقبول** | أقلّ من دقيقتين |
| **نقيس** | الزمن · عدد الضغطات · التردّد · طلب المساعدة |

### السيناريو ٢: معرفة ما يُزرع

> «أنت في شهر يناير وتريد أن تعرف **ماذا تزرع هذا الشهر**.»

| | |
|---|---|
| **المسار المتوقَّع** | أيّ صفحة ← الورش ← الجدول ← صفّ يناير |
| **النجاح** | قال «نعناع أو بقدونس أو كزبرة» |
| **الزمن المقبول** | أقلّ من ٤٥ ثانية |
| **نقيس** | هل بحث في «دليل المبتدئ» أوّلاً؟ ← **الفرضية ١** |

### السيناريو ٣: التطوّع

> «أعجبتك المبادرة وتريد **التطوّع معهم**.»

| | |
|---|---|
| **المسار المتوقَّع** | من نحن ← تواصل ← اختيار «التطوّع» ← إرسال |
| **النجاح** | أرسل النموذج و«التطوّع» مختار |
| **الزمن المقبول** | أقلّ من دقيقة ونصف |
| **نقيس** | هل انتبه إلى مربّعات الاختيار؟ ← **الفرضية ٤** |

## كيف تُدار الجلسة

| | |
|---|---|
| **العدد** | ٣ مستخدمين على الأقلّ، من خارج المجموعة |
| **الأجهزة** | واحدٌ على الهاتف، واثنان على الحاسوب |
| **المدّة** | ١٥ دقيقة لكلٍّ |

**قواعدُ ثلاث لا تُكسر:**

1. **لا تساعد.** الصمتُ المحرج بياناتٌ ثمينة. وإن سأل «ماذا أفعل؟» فقل:
   «ماذا تتوقّع أنت؟»
2. **اطلب التفكير بصوتٍ عالٍ.** «قل لي ما يدور في ذهنك وأنت تبحث.»
3. **سجّل ما فعل لا ما قال.** من يقول «واضح» ويقضي دقيقتين في البحث،
   الحقيقةُ فعلُه.
